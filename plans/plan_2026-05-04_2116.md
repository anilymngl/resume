## Goal

A sampler of **compact, distilled "journey as art"** pieces — each ~1 page, radically shorter than the full resume, each one a different visual metaphor for the career arc. You pick the winner; losers get deleted or archived.

## The 4 proposed directions

Each file is fully standalone (no build step, inline CSS, SVG inline). All use the same distilled content spine:


### A. `experimental_art/subway.html` — Career Transit Map
- SVG subway-style map. Three colored lines: **Data** (blue), **AI** (red), **Retail/Decision** (green).
- Stations = roles/projects. Interchange stations where lines cross (BlueCloud = where Data and AI meet).
- Typography: Helvetica-like sans, station dots, minimal label density.
- Bottom: 1 paragraph "legend" in plain English.

### B. `experimental_art/ridgeline.html` — Horizon / Landscape
- Single hand-drawn-feel SVG ridge line reading left-to-right = time.
- Peaks = shipped outcomes (Invent electronics retailer metrics, Cortex eval frameworks, RAG Glassbox).
- Valleys = transitions / learning periods (honest, not hidden).
- Ink-on-cream palette, one accent color. Year ticks along the horizon.
- Caption below each peak: 1 line, no jargon.

### C. `experimental_art/constellation.html` — Star Map
- Dark navy canvas. Each star = a project or role; star size = scope.
- Thin lines connect related work (e.g., Semantic View Factory ↔ Cortex Analyst Eval).
- Side panel: "coordinates" table — year, star name, stack in mono font.
- Feels like an observatory chart, not a dashboard.

### D. `experimental_art/broadsheet.html` — One-Page Zine
- Pure typographic art. Big serif headline, rule lines, a single hand-drawn arrow curving through 3 chapter markers.
- ~250 words total, pull-quotes for the durable positioning line and one honest metric.
- Feels like a printed broadsheet / liner notes. No icons, no chips, no grids.
