Concrete Pattern

Separate scoring for data results, SQL logic, and answer quality. A Cortex Analyst response can be numerically correct but use the wrong aggregation grain (false-green), or correct in logic but mislabeled (amber). We separated three scoring surfaces — data results, SQL correctness, and answer quality — with semantic judge checks and high-confidence override rules. This separation caught failures that single-surface scoring missed and produced a structured tuning backlog for each Semantic View fix.
